\section{\mso interpretations}
\label{sec:mso-interpretation}



In \cref{sec:logic} we showed that the regular string-to-string functions are exactly those functions that can be defined by \mso transductions. In the definition of  an \mso transduction, see \cref{def:mso-transduction}, we require that the universe formula uses a linear type, i.e.~element of the output structure is defined by using a single element of the input structure. What if we lift this restriction? 


\begin{definition}[\mso interpretation] \label{def:mso-interpretation}
    A string-to-string \mso interpretation is defined in the same way as an \mso transduction, except that we do not require the type $\tau$ to be linear. 
\end{definition}

In this section, we prove that the \mso interpretations are exactly the polyregular functions.  (The theorem below is stated for string-to-string functions, but we will also prove it in the slightly more general setting of type-to-type functions.)
\begin{theorem}\label{thm:mso-interpretation}
A string-to-string function is polyregular if and only if it can be defined by a string-to-string \mso interpretation.
\end{theorem}

The easy part of the theorem is the implication
\begin{align*}
\text{polyregular} \subseteq \text{\mso interpretation}.
\end{align*}
As we have shown in \cref{lem:reachability-pebble-automaton}, for each pebble transducer there is  an \mso formula that defines the reachability relation between  configurations. Using this formula, we can write a  formula that selects configurations which are: (a) reachable from the initial configuration, and (b)  produce an output letter in the next step. This formula will be the universe formula of the interpretation. The order formula  is then reachability between configurations, restricted to configurations selected by the universe formula. Finally, the label formulas are obtained by consulting the transition function of the transducer to see what letter is produced. 


The hard part of the theorem is the converse implication:
\begin{align*}
\text{polyregular} \supseteq \text{\mso interpretation}.
\end{align*}
The difficulty is that the automata models for polyregular functions, such as for transducers or pebble transducers, have a stack discipline on their loops, which is not aparent in an \mso interpretation. As we know from \cref{exer:no-stack-discipline}, without stack discipline pebble transducers are not continuous, and even equivalent to deterministic logarithmic space. Therefore, the heart of the proof is showing that an \mso interpretation must have some implicit stack discipline. This will be the content of the rest of this section. 

The plan is as follows.
 In \cref{sec:quantifier-elimination},  we show
 every \mso interpretation can be factored into two steps: a rational function  followed by a quantifier-free interpretation, i.e.
\begin{align*}
\text{\mso interpretations} = \text{rational}; \text{quantifier-free interpretations.}
\end{align*}
 Since polyregular functions are closed under composition and contain the rational functions, this means that the difficult inclusion  from \cref{thm:mso-interpretation} reduces to its quantifier-free special case, i.e. 
 \begin{align*}
\text{polyregular} \supseteq \text{quantifier-free interpretations}.
 \end{align*}
The next step of the proof is \cref{sec:rational-domination}, where we show that quantifier-free orders on tuples of positions have a precedence on the coordinates, which is where the implicit stack discipline emerges. Finally, in \cref{sec:using-domination-lemma} we put the results together to prove \cref{thm:mso-interpretation}, by using the precedence order to simulate compute an quantifier-free interpretation using a for-transducer.

\subsection{Quantifier elimination}
\label{sec:quantifier-elimination}
The goal of this section is to show that every \mso interpretation can be decomposed as a rational function followed by a quantifier-free interpretation. This decomposition will be based on the Factorisation Forest Theorem, which is a powerful result from semigroup theory. The rough idea is that the rational function in the first step produces a factorisation tree (which is the subject of the Factorisation Forest Theorem), which contains enough information so that it can be interpreted in a quantifier-free way in the second step.  The argument has three steps. In \cref{sec:logical-structures-for-types}, we explain how factorisation trees are represented as logical structures, since the output of the rational function will not be strings. In \cref{sec:factorisation-forests}, we prove the  Factorisation Forest Theorem. Finally, in \cref{sec:proof-of-quantifier-free-interpretation-decomposition} we put everything together to prove the decomposition result. 
\subsubsection*{Logical structures for types}
\label{sec:logical-structures-for-types}

% Our intended application is to use quantifier-free formulas, and therefore we will have to be careful about the choice of vocabulary, since quantifier-free formulas are sensitive to such choices (for example, the successor can be defined from the order, but not in a quantifier-free way).

In our quantifier elimination argument, the intermediate structures (the outputs of the rational function and the inputs of the quantifier-free interpretation) will not be strings, but a certain kind of bounded height trees. These trees will be viewed as elements of some type (as in \cref{def:types}). We already know how types can be outputs of rational functions, see \cref{sec:rational-terms}, but we also need to explain how types can be used as inputs or outputs of quantifier-free interpretations. This requires a representation of the inputs and outputs as relational structures, which we now explain. The idea is to think of an element of a type as a its syntax tree. The notion of syntax tree is best explained in a picture:
\mypic{58}
An important property of syntax trees is that if a type $A$ is fixed, then syntax trees of elements $a \in A$ have bounded height. The syntax tree is viewed as a relational structure, according to the the following definition., 

\begin{definition}
    [Tree structure] \label{def:tree-model} Let $A$ be a type. The \emph{tree structure} associated to $a \in A$ is defined as follows. The universe is the nodes of the  syntax tree. The structure has unary relations for the  possible labels
    \begin{align*}
    \times \quad * \quad 1 \quad  \leftterm \quad \rightterm,
    \end{align*}
    as well as the following relations:
        \begin{align*}
        \text{parent:} \quad &  \setbuild{(x,y)}{$x$ is the parent of $y$}\\
        \text{sibling order:} \quad & \setbuild{(x,y)}{$x$ and $y$ have the same parent, and $y$ is after $x$}\\
        \text{sibling successor:} \quad & \setbuild{(x,y)}{$x$ is immediately before $y$ in the sibling order} \\
        \text{first child:} \quad & \setbuild{x}{$x$ is the first child of its parent} \\
        \text{last child:} \quad & \setbuild{x}{$x$ is the last child of its parent} \\
        \text{root:} \quad & \setbuild{x}{$x$ is the root of the tree} 
        \end{align*}
\end{definition}

Some of the relations above may seem redundant. For example, the root can be defined in terms of the parent relation: a node without a parent. However, this definition requires a quantifier, and we will be interested in quantifier-free formulas. Similar comments apply to the sibling successor, first child, and last child relations.  The vocabulary of the tree structure does not depend on the type, and we will call it the \emph{tree vocabulary}.  When we talk about interpretations that input and output types, we will assume that the input and output are represented as tree structures, as in \cref{def:tree-model}. If the type is $A^*$ where $A$ is a finite alphabet, then there is some ambiguity -- since strings can be represented either as labelled linear orders, according to the representation described in \cref{sec:logic}, or as tree structures. There is not an important difference (the tree structure has an extra root, and some more relations such as the successor),  but  we will indicate our choice whenever it arises. 

\begin{myexample}
    Consider a function 
    \begin{align*}
    \onetype^* \xrightarrow f \onetype^*
    \end{align*}
    which extends the input string by adding one extra letter. We view this function as a type-to-type interpetation, which means that both inputs and outputs are repesented as tree structures. The universe of the output structure is described using  variable type $n+1$, which means that there are two variants: one for elements of the input structure, plus one for defining an extra node. 
    The universe formula is ``true'' since all input nodes are used, plus the extra node. The formula 
    \begin{align*}
    \varphi_\parent(x : n+1, y : n+1)
    \end{align*}
    which defines the parent relation of the output structure is as follows:
    \begin{align*}
    \myunderbrace{(\summand 1 x \land \summand 1 y \land \parent(x(1),y(1)))}{if both $x$ and $y$ are from the first variant, \\ then we use the parent relation from the input} \lor
    \myunderbrace{(\summand 2 y \land \rootrel(x(1)))}{if $y$ is the extra node \\ from the second variant \\ then its parent is the input root}.
    \end{align*}
    In the second disjunct from the above formula, we do not need to assert that $x$ uses the first variant, since $\rootrel(x(1))$ requires that the coordinate is defined, which can only happen when $x$ uses the first variant. The formulas defining the remaining relations -- sibling order, sibling successor, first child, last child, and the labels -- are left as an exercise for the reader.
\end{myexample}




    
We are now ready to state the quantifier-free decomposition result.

\begin{lemma}\label{lem:quantifier-free-interpretation-decomposition}
Every  string-to-string \mso interpretation
   \begin{align*}
   A^* \xrightarrow f B^*
   \end{align*}
   can be decomposed as 
   \[
   \begin{tikzcd}
   A^* 
   \ar[r,"f_1"]
   &
   C
   \ar[r,"f_2"]
    &
    B^*
   \end{tikzcd}
   \]
   where  $C$ is some type, $f_1$ is a rational function  and $f_2$ is a quantifier-free   interpretation. In the interpretation $f_2$, inputs are represented as tree structures and outputs are represented as labelled linear orders. 
\end{lemma}

 The above lemma is stated for string-to-string functions, but the proof can be extended to cover also type-to-type functions. The assumption that inputs of $f_2$ are represented as tree structures is important for the lemma, but the assumption that outputs are represented as labelled linear orders is not (we use the labelled linear orders for the outputs so as to be consistent with the way that outputs of $f$ are represented).    The rest of   \cref{lem:quantifier-free-interpretation-decomposition} is devoted to proving the  lemma.

 \end{claim}

 \end{proof}

    \facttype {h, k} \xrightarrow {e}  B^*

such that $f = g;e$, as required by the lemma. In this interpretaton, the elements of the output structure will be described using tuples of $d$ factorisation paths. \subsection{The domination lemma} 
\label{sec:rational-domination}
As we have explained before, the main difficulty in the proof is showing that definable orders on tuples of positions are essentially lexicographic. The actual formalisation of this statement will be rather technical, and presented in the following section. However, we can begin with a simplified version that contains some of the main ideas, and which is based on rational numbers. 


To explain the importance of lexicographic orders, we will first illustrate it on a clean example which involves the ordered rational numbers 
\begin{align*}
(\Rat, <).
\end{align*}
We will discuss linear orders on $d$-tuples of rationals that can be defined by formulas
\begin{align*}
\varphi(x_1,\ldots,x_d,y_1,\ldots,y_d).
\end{align*}
The formulas in question will be quantifier-free, but this restriction is not essential, since the rational ordering has quantifier elimination, so that even higher-order logic collapses to the quantifier-free fragment.
Also, we will only care about growing tuples  
\begin{align*}
\Rat^{(d)} = \setbuild { x \in \Rat^d }{$x[1] < \cdots < x[d]$}.
\end{align*}
This will make the result cleaner, since otherwise the definable orders could make a case distinction between various order types of tuples, leading to more possiblities.
  

In dimension $d=1$ there are only two possibilities for the order: the original order $<$ and its opposite. In dimension $d=2$, there are four possibilities, namely the  lexicographic orders: we can give priority to the first or second coordinate, and for each of the coordinates we can choose the original order or its opposite.  As we will  see, this pattern continues in higher dimensions.  The crucial observation is the following lemma, which says that any definable order on growing tuples of rationals must give priority to one of the coordinates.

    \begin{lemma}[Rational Domination Lemma]\label{lem:rational-dominating-coordinate}
        Consider an linear order   $\prec$ on $\Rat^{(d)}$
    that is defined by a quantifier-free formula. Then there is a dominating coordinate, i.e.~a coordinate $i \in \set{1,\ldots,d}$ such that one of the following two conditions holds:
\begin{itemize}
    \item $x[i] < y[i]  \quad \Rightarrow \quad x \prec y 
\quad \text{for every  $x,y \in \Rat^{(d)}$}$; or
    \item $x[i] < y[i]  \quad \Rightarrow \quad x \succ y 
\quad \text{for every  $x,y \in \Rat^{(d)}$}$.
\end{itemize}
    \end{lemma}

Before proving the lemma, we remark that it can be used to draw a stronger conclusion: the order must necessarily be lexicographic, i.e.~we first look the dominating coordinate, and in case of equality we look at some other coordinate, and so on. This stronger conclusion is proved in \cref{exer:rational-lexicographic}. For the purposes of our transducer application, we only need the weaker formulation of the lemma that is given above. 

\begin{proof}[Proof of \cref{lem:rational-dominating-coordinate}]
        We use the names \emph{positive domination} and \emph{negative domination} for the following two conditions in the conclusion of the lemma, respectively.  
    Choose some  tuples 
        \begin{align*}
        x_0,\ldots,x_d, x \in \Rat^{(d)}
        \end{align*}
        such that $x_i$ is placed between coordinates $i$ and $i+1$ of the tuple $x$, as shown in the following picture for $d=3$:
        \mypic{56}

        Since the quantifier-free relation between $x_i$ and $x_{i+1}$ is always the same, we know that defined order must order them monotonically, and so we have either
        \begin{align*}
        x_0 \prec \cdots \prec x_d \quad \text{or} \quad x_0 \succ \cdots \succ x_d.
        \end{align*}
        By symmetry, we consider the first case, where we will prove positive domination for the dominating coordinate. (The second case leads to negative domination.)  Choose the mininimal index $i$ such that $x \prec x_i$. 
        This index must belong to $\set{1,\ldots,d}$ since  $x$ is strictly between $x_0$ and $x_d$.  Here is a picture for $d=3$ and $i=2$:
        \mypic{57}
        We will show that conclusion of the lemma for coordinate $i$ and positive domination. Indeed, take some $y \in \Rat^{(d)}$ such that coordinate $i$ of $x$ is to the left of the same coordinate in $y$. To prove the desired conclusion $x \prec y$, we will find a tuple that is strictly between them in the right order. Because the rational numbers are dense, we can find a  tuple $z$ which: (a) is strictly between coordinates $i$ of $x$ and $y$, respectively; and (b)  crosses neither $x$ nor $y$, which means that every coordinate of $x$ or $y$ is either entirely to the left or entirely to the right of $z$. Because $z$ is to the right of coordinate $i$ in $x$ and  does not cross $x$, we know that $x \prec z$. Because $z$ is to the left of coordinate $i$ in  $y$ and it does not cross $y$, we know that $z \prec y$. Therefore, we have $x \prec z \prec y$, which implies $x \prec y$.
        \end{proof}

\begin{align*}
\Rat \xrightarrow \lambda A
\end{align*}
 such that every label is dense, i.e.~betwen every two rationls we wll find all possible labels. (As we show in \cref{exer:shuffle-unique}, there is not much choice going on, since any two such labellings are isomorphic.) We think of this labelling as a structure, which is obtained by extending the rational order with unary predicates $a(x)$ for every $a \in A$.  Using the same proof as in the ulabelled version from \cref{lem:}

 \begin{lemma}\label{lem:labelled-order}
    Let $A$ be a finite set, let $a_1,\ldots,a_d \in A$ and consider a linear order on 
\begin{align*}
    \setbuild{ x \in \Rat^d}{ $x$ is growing and the labels under $\lambda$ are $a_1,\ldots,a_d$}
\end{align*}
that is defined by a quantifier-free formula. Then there is a dominating coordinate. 
 \end{lemma}







A quantifier-free formula is called \emph{saturated} (the usual name is quantifier-free type, but the word type is already used here for a different meaning)  it contains all information about the relations which concern its arguments. Every quantifier-free formula is equivalent to a disjunction of saturated formulas. Therefore, thanks to the Merging Lemma, it is enough to prove \cref{lem:quantifier-free-tuple-enumerator-is-for-definable} for quantifier-free definable tuple enumerators in which the universe formula is saturated. The key technical result will be in the following lemma.


\newcommand{\vars}{\mathrm{vars}}
\begin{lemma}[Domination Lemma]\label{lem:domination}
    Consider a quantifier-free definable tuple enumerator where:
\begin{itemize}
    \item the input type is a list type  $A^*$;
    \item the dimension is $d$;
    \item the universe formula $\varphi$  is saturated;
\end{itemize}
Then there exist: 
\begin{itemize}
    \item a variable $x \in \vars (\varphi)$ which  is a child of the root according to $\varphi$
    \item a distance threshold $t \in \set{0,1,\ldots}$
\end{itemize}
such that if we use the following notation for $a \in A$:
\begin{itemize}
    \item $<_a$ is the order on children of the root in  $a$;
    \item $a^\varphi$ is the set of tuples selected by the universe formula in $a$;
    \item $\prec_a$ is the order on $a^\varphi$  defined by the order formula; 
\end{itemize}
then one of the following two conditions holds:
\begin{itemize}
    \item $\alpha(x) + t <_a \beta(x)$ implies $\alpha \prec_a \beta$ for every $a \in A$ and $\alpha,\beta  \in \varphi^a$; or
    \item $\alpha(x) + t <_a \beta(x)$ implies $\alpha \succ_a \beta$ for every $a \in A$ and $\alpha,\beta  \in \varphi^a$; or
\end{itemize}
\end{lemma}

A quantifier-free formula with free variables $X$ is called a \emph{quantifier-free type} if it specifies all relations between its variables. This means that it is a conjuction of atomic formulas and negations of atomic formulas, which contains every atomic formula or its negation. For example, if the vocabulary contains equality only, then an example of a quantifier-free type over variables $x,y,z$ is 
\begin{align*}
x = x \land x = y \land x \neq z \land y = x \land y = y \land y \neq z \land z \neq x \land z \neq y \land z = z.
\end{align*}
Up to logical equivalence, the example quantifier-free type above can be written as $x = y \land x \neq z$. We will be interested in quantifier-free types that describe tree arrangements: a quantifier-free type over the tree vocabulary is called a \emph{tree arrangement} if it is closed under the parent relation: for every free variable $x \in X$ which is not a root (a notion that is meaningful thanks to the first condition), there is a variable $y \in X$ such that $\parent(y,x)$ holds.

(1)  and (2) for every free variable $x \in X$ which is not a root (a notion that is meaningful thanks to the first condition), there is a variable $y \in X$ such that $x$ is a child of $y$. In other words, the formula defines a tree arrangement on its variables.  The universe formula in the above lemma is saturated, and therefore it defines a tree arrangement.

\begin{lemma}[Domination Lemma]\label{lem:domination}
    Let  s
\begin{itemize}
    \item $A$ be a type;
    \item $X$ be a finite set of variables;
    \item $\varphi$ be a quantifier-free formula with  variables $X$ which defines a tree arrangment;
    \item $\psi$ be a quantifier-free formula with variables $X + X$ such that for every $a \in A$,  $\psi$ defines a linear order  on the tuples selected by $\varphi$ in $a$;
\end{itemize}
Then there exist: 
\begin{itemize}
    \item a variable $x \in X$ which describes a child of the root according to $\varphi$;
    \item a distance threshold $t \in \set{0,1,\ldots}$
\end{itemize}
such that if we use the following notation for $a \in A$:
\begin{itemize}
    \item $<_a$ is the order on children of the root in  $a$;
    \item $\prec_a$ is the order defined by $\psi$ on tuples selected by $\varphi$;
\end{itemize}
then one of the following two conditions holds:
\begin{itemize}
    \item $\alpha(x) + t <_a \beta(x)$ implies $\alpha \prec_a \beta$ for every $a \in A$ and $\alpha,\beta  \in a^X$ selected by $\varphi$;
    \item $\alpha(x) + t <_a \beta(x)$ implies $\alpha \succ_a \beta$ for every $a \in A$ and $\alpha,\beta  \in \varphi^X$ selected by $\varphi$.
\end{itemize}
\end{lemma}



\begin{proof}
    The proof has two steps, with the first one being the major one: (1) we prove the conclusion of the lemma for tuples that are disconnected; and (2) we use the first result to conclude the proof for all tuples. In step (1), we will use the results on labelled rational numbers from \cref{sec:rational-domination}. 


    \paragraph*{Disconnected tuples.}
    Consider two tuples $\alpha, \beta \in \varphi^a$. We say that these tuples  are \emph{connected} if some coordinate of $\alpha$ is related to some coordinate of $\beta$ by one of: equality,  successor and  predecessor relation. If the tuples are not connected, then we call them \emph{disconnected}. In the first step, we will show that the domination lemma holds for disconnected tuples, even without the distance threshold.

    \begin{claim}\label{claim:domination-lemma-discconnected}
        There is some variable $x$ which is a child of the root such that either
    \begin{itemize}
    \item $\alpha(x) <_a \beta(x)$ implies $\alpha \prec_a \beta$ for every $a \in A$ and disconnected $\alpha,\beta  \in \varphi^a$; or
    \item $\alpha(x)  <_a \beta(x)$ implies $\alpha \succ_a \beta$ for every $a \in A$ and disconnected $\alpha,\beta  \in \varphi^a$.
\end{itemize}
\end{claim}

    The proof of this claim is rather long and will require some preparation. We say that a saturated formula $\varphi$ is connected if every (equivalently, some) valuation that satisfies it is connected. For two saturated formulas $\varphi_1$ and $\varphi_2$ with disjoint variables, we write $\varphi_1 \ll \varphi_2$ for the saturated forrmula which says that $\varphi_1$ and $\varphi_2$ are satisfied, and that every root-child variable of $\varphi_1$ is to at least two positions to the left of every root variable of $\varphi_2$. 

    \begin{claim}
        Every saturated formula $\varphi$ can be written as 
        \begin{align*}
        \varphi = \varphi_1  \ll \cdots \ll \varphi_\ell
        \end{align*}
        for some saturated formulas $\varphi_1,\ldots,\varphi_\ell$ which are connected.
    \end{claim}


    Apply the above claim to the universe formula $\varphi$, yielding formulas $\varphi_1,\ldots,\varphi_\ell$. Consider a labelling 
    \begin{align*}
    \Rat \xrightarrow \lambda \set{\varphi_1,\ldots,\varphi_n}
    \end{align*}
    where each labelling is dense. We will now apply the labelled version of the Rational Domination Lemma to  a certain ordering $\sqsubset$ on 
    \begin{align}\label{eq:domination-lemma-rational-order}
    \setbuild { \alpha \in \Rat^\ell} {$\alpha$ is growing and the labels under $\lambda$ are $\varphi_1,\ldots,\varphi_\ell$}.
    \end{align}
        This ordering is defined as follows. First replace each rational number $q \in \Rat$ by a structure that represents the saturated formula in the label $\lambda(q)$. The result is some infinite structure, call it $a_\lambda$ over the vocabulary of  $A^*$. Each tuple $\alpha \in \Rat^{(d)}$ gives rise to some tuple in the limit structure $\alpha_\lambda$.  This tuple, call it $\alpha_\lambda$,  satisfies the universe formula. We are now ready to define the ordering:
        \begin{align*}
        \alpha \sqsubset \beta \quad \text{if} \quad \text{ $(\alpha_\lambda,\beta_\lambda)$ satisfies the order formula.}

\begin{definition}[Tuple enumerator]\label{def:tuple-enumerator}
    A tuple enumerator of input type $A$ and dimension $d$ is a function of the following form:
    \begin{itemize}
        \item \textbf{Input.} $a \in A$;
        \item \textbf{Output.} a non-repeating list of $d$-tuples of positions in $a$.
    \end{itemize}
\end{definition}

We will have two formalisms for specifying tuple enumerators. The first formalism is based on logic, and it corresponds to interpretations. We say that  tuple enumerator is called \emph{quantifier-free definable} if there are two  quantifier-free formulas, over the vocabulary of the input type $A$, namely
    \begin{itemize}
        \item a formula with $d$ free variables, called the \emph{universe formula}; and 
        \item a  formula with $2d$ free variables, called the \emph{order formula},
    \end{itemize}
    such that for every $a \in A$, the output of the tuple enumerator is the list of $d$-tuples of positions in the structure of $a$ that satisfy the universe formula, ordered according to the order formula. The other formalism is based on for-transducers, and it is defined just like a for-transduceer, except that instead of outputting letters, we have output instructions of the form 
\begin{lstlisting}

\end{lstlisting}
that uses position variables. 

A quantifier-free interpretation can be seen as a tuple enumerator, together with quantifier-free formulas which choose the output label for each tuple. Therefore, if we manage to convert the tuple enumerator into a for-transducer, we will also have a for-transducer for the corresponding function with string outputs: we simple need to replace each instruction that outputs a tuple of positions with an instruction that outputs the corresponding output letter. Therefore, the main technical difficulty is to show that every quantifier-free definable tuple enumerator can be implemented by a for-transducer. This is the content of the following lemma.
\begin{lemma}\label{lem:quantifier-free-tuple-enumerator-is-for-definable}
    If a tuple enumerator is quantifier-free definable, then it is computed by a for-transducer.
\end{lemma}
