The formalisation now identifies the results of the book by their LaTeX labels instead of by their numbers, and the correspondence is checked by Lean.

**Reference relabelling (all Lean sources and docs).** Every reference of the form `Theorem C.1.4` in the docstrings and comments of `transducer-lean/RequestProject/**.lean`, in `THEOREMS.md` and in `README.md` was replaced by the LaTeX label of the environment, in backticks (`` Theorem `thm:decidable-equivalence-regular` ``). Numbers were dropped from the headers of the documentation tables, and sections/subsections — which carry no labels — are referred to by their titles (`Section *Rational relations and weighted automata*`). As agreed, the Lean declarations keep their descriptive names, and no `\label` was added to the `.tex` sources: the ~20 environments of the book that carry no label were given descriptive placeholder tags with the prefix `nolabel:` (e.g. `nolabel:thm-krohn-rhodes`), so that a real label can later replace them.

**Machine-checked label index.** The new file `transducer-lean/RequestProject/Labels.lean` (imported by `RequestProject.lean`) makes the correspondence part of the development: in the namespace `Transducers.Book` it declares, for each formalised result, an alias whose Lean name *is* the label of the result (`alias «thm:decidable-equivalence-regular» := Transducers.regular_equivalence_decidable`), so a wrong or stale declaration name in the documentation breaks the build. A result formalised by several declarations gets `«label#2»`, `«label#3»`, …. Each alias is followed by an assertion — `assert_no_sorry` or `assert_uses_sorry`, both implemented with `Lean.collectAxioms` — that checks whether the result is proved outright or still depends on `sorry`, so the statuses recorded in `THEOREMS.md` are checked too. The file currently contains 101 aliases covering 85 results, and ends with a comment listing, with a reason for each, the theorem-like environments of the book that are not aliased, so all of them are accounted for.

**Documentation and tooling.** `transducer-lean/LABELS.md` explains the convention, describes the Lean-checked index, and tabulates number → kind → label → LaTeX file for all 100 environments plus the section/subsection titles; `THEOREMS.md` and `README.md` point at it and list the new file. The scripts under `tools/` reproduce the work: `tex_numbering.py` replays the numbering scheme of `macros.sty` over `main.tex`, `relabel.py` performs the rewriting and has a `--check` mode (currently reporting no leftover numbered reference), `relabel_manual.py` handles the few bare-number references, and `gen_labels.py` regenerates `Labels.lean` from the status tables of `THEOREMS.md`.
