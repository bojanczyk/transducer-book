## What was done

The target of this task was **Theorem C.3.2 (`Transducers.sst_iff_regular`)** — streaming string transducers compute exactly the regular functions. The direction `regular ⊆ sst` was already in place from earlier work; the missing half, `sst ⊆ two-way` (and hence `sst ⊆ regular` via Theorem C.2.9), is now **proved and sorry-free**. `lake build` succeeds with no errors.

Two new files carry the construction:

* **`RequestProject/PartC/SSTNorm.lean`** — *normalised* streaming string transducers (`Transducers.NSST`: the register update depends only on the letter read, the state only on the last letter, and no register occurs twice in a final output string) and the reduction of an arbitrary sst to one (`Transducers.exists_nsst_of_sst`). Two obstacles to the traversal are removed here: the state of the sst before a position, which the two-way head cannot see, is put into the input by a Mealy annotation; and the repeated register occurrences in a final output string, which the copyless restriction does not forbid, are separated by keeping `K + 1` copies of every register and tagging the occurrences with pairwise distinct copies.
* **`RequestProject/PartC/SSTWalk.lean`** — the two-way transducer that performs the depth-first traversal of the register flow tree (`Transducers.isTwoWay_of_nsst`), with the two correctness lemmas `NSSTWalk.scan` (a nested induction on the position and on the length of the suffix being expanded) and `NSSTWalk.top`. The copyless restriction enters through `NSSTWalk.findReg_eq`: the place at which an expansion has to be resumed is a function of the register and of the letter at the position returned to.

`RequestProject/PartC/SSTTwoWay.lean` assembles them into `Transducers.isTwoWay_of_isSST`, using that the annotation is rational and that two-way transducers are closed under pre-composition with rational functions (Corollary C.2.7).
