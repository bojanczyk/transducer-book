**How it is proved.** The direction from for-transducers to pebble transducers was already in the project (`PebbleForTop.lean`). For the other direction I proved that a pebble transducer computes a polyregular function, which is a for-transducer by Theorem `thm:for-transducers-are-polyregular`. The book gets this from the reachability analysis of a pebble automaton (Lemma `lem:reachability-pebble-automaton` and the claims inside its proof, which are internal steps and are deliberately not formalised as numbered results); I used the same idea — the run above the bottom pebble is a run of a machine with one pebble fewer — but organised as an induction on the number of pebbles, stated entirely in the vocabulary of pebble transducers. All the existing definitions (`Pebble`, `PebbleView`, `viewOf`, `PebbleAction`, `IsPebbleTransducer`, `IsPolyregular`, `markedSquare`, …) are reused unchanged.
