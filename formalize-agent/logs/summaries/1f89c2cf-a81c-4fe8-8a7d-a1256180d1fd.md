## What I found

`EvenParityNeedsThreeStates` — i.e. `MinimalUnambiguousSize evenParity 3` — **cannot be discharged, because it is false** in the model of `def:nfa-with-output` as formalised in this project, where a transition may read an *arbitrary* input string. Two states already suffice:

    init {i}, final {f},  i --ε/1--> f,  i --a/0--> f,  f --aa/ε--> f

The accepting run over `aⁿ` guesses the parity bit first and then reads the input two letters at a time; there is exactly one accepting run per input, and its output is the parity bit. So I proved the negation instead of the hypothesis, and then proved what the exercise actually needs, in both models.
