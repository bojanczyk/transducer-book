## What was done

The book's string encoding of the reachable configuration graph of a two-way transducer (Section C.2, alphabet `C`) is now a real object of the formalisation, and both lemmas the book states about it are proved. Four new files in `RequestProject/PartC/`:

* **`ConfGraph.lean`** — the alphabet and the representation. `Transducers.VOut` is the outgoing edge of a vertex (none / an edge to a state of the *other* copy with an output label / an edge to the halting vertex); `Transducers.Slice Q L = Bool × Q → VOut Q L` is a letter of `C` for a non-empty input, i.e. a bipartite graph on two copies of the state set with at most one outgoing edge per vertex, going to the other copy, labelled by an output string; `Transducers.CLet Q L = Slice Q L ⊕ Option L` adds the book's special letter for the empty input. Labels range over `TwoWay.Lab M`, the finite set of output strings occurring in the transition function — the book's reason for `C` being finite. `TwoWay.enc M w` is the representation of the reachable configuration graph (one slice per position; a vertex the run does not visit gets no edge), and `TwoWay.pathTrans M` is the two-way transducer over `C` that walks along a represented graph and prints the labels it meets, which is what "the output string of the configuration graph" means.
* **`ConfGraphRun.lean`** — agreement with the run semantics already in the project (`TwoWayRun.lean`): `TwoWay.computes_enc` (if `M` outputs `v` on `w`, then `pathTrans M` outputs `v` on `enc M w`) and `TwoWay.computes_enc_iff` (the equivalence, for an input on which `M` halts). The two views are therefore interchangeable.
* **`ConfGraphAnnot.lean`** — the representation as a letter-to-letter image of the annotation of `TwoWayAnnot.lean` (`TwoWay.enc_eq_map_annot`), and the regularity of the language of correct annotations (`TwoWay.validLang_isRegular`). This is where the reachability information comes from, reusing `TwoWayVisit.lean`/`TwoWayAnnot.lean` rather than rebuilding it.
* **`ConfGraphReg.lean`** — the main observation and the two lemmas.

The three results are restated in `RequestProject/PartC/Statements.lean` and aliased in `RequestProject/Labels.lean` (which `tools/gen_labels.py --check` now accepts).
